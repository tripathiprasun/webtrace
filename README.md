# WebTrace

WebTrace is a web-based website behavior analysis tool. Enter a URL, and WebTrace launches a controlled Chromium browser using Playwright to observe page load behavior, collect network and resource information, and present results through a professional developer-oriented interface.

## Tech Stack

**Backend:**
- Python
- Django
- Playwright

**Frontend:**
- Django Templates
- Vanilla JavaScript
- Tailwind CSS
- Cytoscape.js
